# Dawn of Titans: прототип боя и королевства (Unreal Engine 5)

Играбельный прототип по мастер-промту (`docs/MasterPrompt.md`): бой этапа **M0** (армии из сотен солдат,
колоссальные титаны, схватка титанов, заклинания за доблесть, ИИ, звёзды, реплеи) и **королевство** как в оригинале
Dawn of Titans: Замок и 20 построек оригинала, золото, еда, самоцветы, камни портала, строители, расширения города,
армия из Казарм с потерями по правилам Лазарета, ростер титанов с опытом, реликвиями-предметами и слиянием,
заклинания из Кузни с улучшениями в Магической башне, набеги и захват земель, титаны-стражи земель. Сверка с оригиналом — `docs/Original_Reference.md`.

Это фанатский прототип, он не связан с NaturalMotion и Zynga. Название игры принадлежит правообладателям,
модели, графика и код здесь свои.

Проект устроен в два слоя:

| Слой | Где | Что делает |
|---|---|---|
| **DoTSim** | `Source/DoTSim` | Детерминированная симуляция боя на чистом C++17: фиксированная точка Q32.32, 30 тиков/с, без float, без движка. Тот же код собирается без Unreal (CMake) для тестов, балансного харнесса и будущего серверного верификатора. |
| **DoTKingdom** | `Source/DoTKingdom` | Детерминированная экономика королевства на том же C++: постройки, уровни, таймеры, ресурсы, строители, камни портала, земли, сохранение. Время передаётся явно, поэтому сервер сможет пересчитать те же действия. |
| **DawnOfTitans** | `Source/DawnOfTitans` | Игровой модуль UE5: режим игры, менеджер боя (шаг симуляции, интерполяция, реплеи), визуализация, камера, управление мышью/тачем, HUD. |
| **Контент** | `Content/Data` | Весь баланс в JSON: войска, титаны, способности, карта Highvale, ИИ-профили, сценарии, постройки и правила королевства (`kingdom/`). Правится без перекомпиляции. |

Ассетов (`.uasset`, `.umap`) нет вообще. Сцена строится кодом из стандартных фигур движка
(`/Engine/BasicShapes`): солдаты в цвете команды, титаны в правильном масштабе, рельеф, лес, река.

---

## 1. Что нужно

- **Unreal Engine 5.5** (в `.uproject` указан 5.5; на 5.4 тоже должно собраться: правый клик по
  `DawnOfTitans.uproject` → *Switch Unreal Engine version*).
- **Windows:** Visual Studio 2022 с нагрузками *Game development with C++* и *Desktop development with C++*
  (MSVC v143, Windows 10/11 SDK). **macOS:** Xcode той версии, которую поддерживает ваш UE.
- Для тестов симуляции без Unreal: CMake ≥ 3.16 и любой C++17-компилятор (MSVC, clang, gcc).

## 2. Сборка и запуск в редакторе

1. Распакуйте архив в путь **без кириллицы и пробелов**, например `C:\Dev\DawnOfTitans`.
2. Правый клик по `DawnOfTitans.uproject` → **Generate Visual Studio project files**.
3. Откройте `DawnOfTitans.sln`. Конфигурация **Development Editor**, платформа **Win64**.
   Соберите проект: *Build → Build Solution*.
   Другой путь: дважды щёлкните `.uproject`, на вопрос о пересборке модулей ответьте **Yes**.
4. Откроется редактор с пустой картой `/Engine/Maps/Entry`. Это нормально: всё поле боя создаётся при старте.
5. Нажмите **Play**. Удобнее всего режим *New Editor Window (PIE)* или *Standalone Game*.

Запуск без редактора, с выбором сценария и сложности:

```
UnrealEditor.exe "C:\Dev\DawnOfTitans\DawnOfTitans.uproject" -game -windowed -ResX=1600 -ResY=900 ^
    -scenario=scenarios/m0_titan_duel.json -enemyai=warlord
```

| Сценарий | Что проверяет |
|---|---|
| `scenarios/m0_sandbox.json` (по умолчанию) | Полный бой: вы (Тор, 6 отрядов) против Талоса и 6 отрядов ИИ. Есть фаза расстановки. |
| `scenarios/m0_titan_duel.json` | Дуэль титанов без расстановки: удары, топот, захват, Clash. |
| `scenarios/m0_cavalry_test.json` | Копейщики в стойке против конницы, обе стороны под ИИ (зрелище и проверка контрзарядов). |

Профили ИИ: `recruit`, `veteran` (по умолчанию), `warlord`, `nightmare`.
Их можно переключать прямо в игре (F7).

> Если на вашей карте или в World Settings переопределён GameMode, бой не запустится.
> Режим игры задан глобально в `Config/DefaultEngine.ini` (`GlobalDefaultGameMode=/Script/DawnOfTitans.DoTGameMode`).
> Для любой своей карты укажите в *World Settings → GameMode Override* класс `DoTGameMode`.

## 3. Демо в браузере и на телефоне (без Unreal)

В папке `Web/` лежит браузерная версия: королевство на парящем острове и бои. Правила там — тот же C++-код
из `Source/DoTSim` и `Source/DoTKingdom`, собранный в WebAssembly. Поверх него работают 3D-вид на Three.js,
тач-управление и интерфейс на русском. Демо открывается на iPhone, Android и компьютере без установки.
Прогресс королевства сохраняется в браузере, а при открытии на claude.ai ещё и в вашем аккаунте.

Запуск готовой сборки (файлы уже лежат в `Web/dist`, нужен интернет для Three.js и шрифтов):

```bash
python3 -m http.server 8000 --directory Web/dist
# открыть http://localhost:8000 (с телефона в той же сети: http://<IP-компьютера>:8000)
```

Пересборка после изменения C++ или контента (нужен Emscripten SDK):

```bash
source /путь/к/emsdk/emsdk_env.sh
Web/build.sh          # Source/DoTSim + Source/DoTKingdom + Web/dot_web.cpp -> Web/dist/dotsim.js (wasm) и dotsim-js.js (запасной JS)
python3 Web/bundle.py # Web/page.html + icons.js + app.js + kingdom.js + Content/Data -> Web/dist/index.html
```

Итоги боя в браузере совпадают байт в байт с нативной сборкой (проверено на 60 боях),
а экран результатов перепроверяет бой по реплею так, как это будет делать сервер.

## 4. Как играть

### Королевство

Игра начинается в королевстве. Числа и правила взяты из вики оригинала там, где они есть
(в окне улучшения видно, какие цифры из вики, а какие наша оценка).

- **Замок** (25 уровней) открывает новые постройки, их количество и уровни. Улучшения требуют построек
  по циклу оригинала: Гарнизон и Лагерь армии, затем Арсенал и Зал титанов, затем Магическая башня и Портал.
- **Золотые шахты и фермы** копят добычу у себя до вместимости. Значок над постройкой собирает её в
  **Золотое хранилище** и **Амбар**. Резервы защищают часть запасов.
- **Строители.** Каждый ведёт одну стройку по реальному времени. Двор строителей нанимает 2-го…5-го
  за самоцветы. Ускорение и недостающие ресурсы тоже покупаются за самоцветы, с подтверждением вторым нажатием.
- **Строить** открывает магазин: выберите постройку и поставьте её на свободное место (зелёная рамка).
  Чтобы переставить постройку, зажмите её. **Расширение** (табличка у края города) убирает лес вокруг.
- **Армия.** Казармы обучают отряды за еду по одному, как в оригинале: Ополчение, Лучники, Копейщики.
  Готовые отряды стоят в Лагере армии, он же задаёт, сколько отрядов идёт в бой (3 на 1-м уровне).
  Арсенал поднимает уровень войск. Без Лазарета каждый раненый в бою отряд погибает, Лазарет возвращает
  отряды, сохранившие 85% бойцов и больше.
- **Титаны** живут в Зале титанов: редкость от одной до четырёх звёзд задаёт предел уровня (20…50), опыт
  даётся за бои. Храм реликвий раз в день бесплатно даёт реликвию-предмет или титана, алтари за самоцветы дают редких.
  С Замка 7 доступно слияние за еду: сила ненужных титанов переходит в выбранного.
- **Реликвии** надеваются на титанов (кнопка «Реликвии» в Зале титанов) и усиливают урон, здоровье или броню.
  Сначала у титана один слот, новые открываются на 20, 30, 40 и 50 уровне. Реликвии изнашиваются в боях;
  с Замка 8 их чинят за еду, отдавая в жертву другие реликвии (шанс растёт с каждой жертвой).
- **Заклинания.** Кузня заклинаний создаёт их в запас за золото, очередь и запас растут с её уровнем.
  Магическая башня улучшает заклинания (+8% к силе за уровень). В бой за землю идут до трёх видов из запаса,
  каждое применение тратит один заряд.
- **Стражи земель.** Нажмите на захваченную землю и поставьте титана: +1% добычи за каждый его уровень, как в оригинале.
- **Атака** открывает земли мира. Перед боем выберите титана, отряды и заклинания. Набег (3 камня портала) приносит золото и еду, захват (6 камней) даёт землю,
  которая потом сама копит доход. Камень портала восстанавливается раз в 7 минут.
  Бой за землю идёт на той же симуляции, что и обычный бой. Отступление или поражение тратит камни.
- **Иконки.** У войск, построек, заклинаний, реликвий (рамка по редкости, сломанные с трещиной), классов титанов,
  алтарей и земель свои рисованные SVG-иконки (`Web/icons.js`); они же в боевых карточках и в подписях над постройками.
- Камера: тяните, щипок или колесо мыши для зума. В меню ☰ есть тренировочные бои и ускорение времени для проверки.

### Бой

**Расстановка.** Перетаскивайте свои отряды внутри синей зоны. **Авто** расставит войска само,
**В бой** (или Enter) начнёт отсчёт.

**Бой.** Нужно уничтожить армию и титана противника до конца таймера. Звёзды даются за 50% разрушения,
за победу над вражеским титаном (если титана у врага нет, эта звезда приходит вместе с первой) и за полную победу.

- Отряды сражаются строем. Важны фланг и тыл, мораль (бегущие отряды), контрудары
  (копья против конницы, конница против лучников и т. д.) и рельеф: холмы, лес, брод, мост, руины.
- Титан наносит размашистые удары, может топнуть, схватить и бросить отряд, а также разогнаться и смести строй.
  Ярость копится в бою и тратится на способности **Q/E**.
- **Clash.** Когда титаны сходятся вплотную, начинается обмен ударами (до трёх).
  Жмите **Пробел** или кнопку CLASH в момент, когда кольцо совпадёт с меткой: Perfect / Good / Miss.
- **Заклинания** стоят доблести. Доблесть растёт со временем и за успехи в бою. Перетащите карту заклинания
  на поле или нажмите Z/X/C/V и кликните по цели. В боях за земли это заклинания из Кузни: на карте видно
  число зарядов, без зарядов карта гаснет. В тренировочных боях — Метеор, Боевые барабаны, Целебный источник.

### Мышь и клавиатура

| Действие | Управление |
|---|---|
| Выбрать отряд или титана | ЛКМ по знамени или юниту, клавиши **1–6**, **T** (титан), **~** (все отряды) |
| Идти / атаковать | ЛКМ по земле или врагу (при выбранном юните) либо ПКМ |
| Атака с разгона | Двойной клик по врагу |
| Нарисовать путь | Протянуть мышь от своего отряда (ЛКМ) или зажать ПКМ |
| Радиальное меню (строй, стойка, стоп, отступить, авто) | Удерживать ЛКМ на юните ~0,3 с |
| Строй / стойка выбранного отряда | **F** / **G** |
| Стоп / отступить | **H** / **R** |
| Способности титана | **Q**, **E** (затем клик по цели, если нужна) |
| Заклинания | **Z X C V** или перетаскивание карты |
| Clash / пауза | **Пробел** |
| Скорость боя 1×/2×/4× | **Tab** |
| Камера | **WASD** или стрелки, перетаскивание пустой земли, колесо (зум) |
| Отмена | **Esc** |
| Перезапуск / реплей последнего боя | **F5** / **F6** |
| Сложность ИИ / авто для всей армии / сохранить реплей | **F7** / **F8** / **F9** |

### Тач (Android / iOS)

Тап выбирает, тап по земле или врагу отдаёт приказ, двойной тап — атака с разгона.
Протяжка от отряда рисует путь, долгое нажатие открывает радиальное меню, два пальца приближают камеру.
Карты заклинаний перетаскиваются на поле.

Реплеи сохраняются в `Saved/Replays/*.replay.json`. Они хранят расстановку, команды и хэши состояния.
Любой реплей можно проверить консольным верификатором (раздел 4).

## 5. Симуляция без Unreal: тесты, реплеи, баланс

```bash
cmake -S SimTools -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
ctest --test-dir build --output-on-failure
```

Получаются три утилиты:

```bash
# Бой ИИ против ИИ, результат и итоговый хэш состояния
build/dot_runner --scenario scenarios/m0_sandbox.json --attacker-ai veteran --defender-ai warlord --seed 42

# Записать реплей и проверить его (как будет делать сервер)
build/dot_runner --scenario scenarios/m0_sandbox.json --attacker-ai veteran --replay-out battle.replay.json
build/dot_runner --verify battle.replay.json

# Детерминизм: N боёв подряд, одна строка на бой "seed hash stars ticks".
# Вывод обязан совпадать байт в байт на любой ОС, компиляторе и CPU.
build/dot_runner --scenario scenarios/m0_sandbox.json --attacker-ai veteran --determinism 20

# Балансный харнесс: случайные армии, процент побед по войскам и титанам (CSV)
build/dot_harness --battles 500 --seed 7 --csv balance.csv
```

На Windows те же команды выполняются в *Developer PowerShell for VS*, а утилиты лежат в `build\Release\`.

CI (`.github/workflows/sim-determinism.yml`) собирает симуляцию на x86-64 (gcc, clang), ARM64, Windows (MSVC)
и WebAssembly, гоняет тесты и сравнивает вывод `--determinism` между всеми платформами.

```

```

## 7. Сборка под iPhone и Android (Unreal)

Проект уже настроен под телефоны:

- альбомная ориентация, Vulkan и OpenGL ES 3.1 на Android, Metal на iOS, 60 кадров/с;
- мобильный forward-рендер с HDR, профили качества по классу устройства (`Config/DefaultDeviceProfiles.ini`);
- HUD увеличивается под пальцы и обходит вырез экрана и полоску «домой» (safe area);
- тач-жесты: тап, двойной тап, протяжка пути, долгое нажатие, щипок для зума.

**Android** (собирается на Windows, macOS или Linux):
1. Установите Android Studio, SDK и NDK по инструкции Epic для вашей версии UE (*Setting up Android SDK and NDK*).
2. В `Config/DefaultEngine.ini` замените `PackageName=com.yourstudio.dawnoftitans` на свой.
3. *Platforms → Android → Package Project*. Получится `.apk`: его можно поставить на телефон через `adb install`
   или скопировать на устройство.

**iPhone** (нужен Mac с Xcode и Apple Developer аккаунтом):
1. В *Project Settings → iOS* укажите свой Bundle Identifier и команду подписи (Signing Team).
2. *Platforms → iOS → Package Project*, затем установка на телефон через Xcode.
   Без Mac можно собирать через удалённый Mac (*Remote Build*), но подпись Apple нужна всё равно.

Папка `Content/Data` попадает в пакет через `DirectoriesToAlwaysStageAsUFS`.

## 8. Важно знать

- Код UE-модуля написан и проверен компилятором на заглушках API движка, но в среде разработки
  не было Unreal Engine. **Первая сборка в настоящем UE может потребовать мелких правок.**
  Если сборка упадёт, пришлите текст первой ошибки из окна *Output*, поправим.
- Симуляция собрана и проверена полностью: 1291 проверка в тестах боя и 184 в тестах королевства,
  детерминизм, ASan/UBSan.
- Экран королевства пока есть только в браузерном демо. В Unreal модуль `DoTKingdom` подключён,
  но 3D-вида королевства там ещё нет.
  Детерминизм подтверждён между x86-64 и WebAssembly (wasm32), ARM64 проверит CI.
- Браузерное демо проверено в Chromium в режимах десктопа, iPhone (горизонтально и вертикально) и iPad.
- Подробности, допущения и план — в `docs/M0_Notes.md`.
